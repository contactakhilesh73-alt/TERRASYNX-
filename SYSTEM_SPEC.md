## 🛡️ THE 5 NON-NEGOTIABLE STRICT RULES

### STRICT RULE #1: Zero Capability Compromise
- Never trim or downgrade system capabilities, responsiveness, or visual class for secondary shortcuts.
- Always implement the gold-standard, production-grade technology stack (Tailwind CSS, React 19, Motion, high-performance engines).
- Never use broken stubs, mock handlers, or half-cooked UI elements.

### STRICT RULE #2: Absolute Authenticity & Zero Latency
- **Zero Fake Tolerance:** 100% cryptographic and origin verification. No opportunity will be visible unless confirmed through official company domains, DNS records, or direct ATS endpoints (Greenhouse, Lever, Ashby, Workday, SmartRecruiters).
- **Zero Opportunity Loss:** Multi-tier polling on primary career feeds to ensure high-priority internships (e.g., OpenAI, Google, Tier-1 Tech) are ingested with zero latency.
- **Sub-Second Expiry Pruning:** When an application closes or deadline expires, the system automatically removes it from the live UI and mutes relevant alert triggers.

### STRICT RULE #3: Autonomous Live Sync & Zero-Refresh Architecture
- **Zero Manual Refresh:** Users never need to press F5/refresh. The UI maintains a continuous reactive live pulse via Server-Sent Events (SSE) and WebSocket-like heartbeat.
- Multi-layer real-time data integrity: Live countdown clocks, active status checks, and instant animated state transitions.

### STRICT RULE #4: Global ATS Spine & Canonical Deduplication
- Core ingestion connects directly to structured career data endpoints rather than brittle, easily-blocked web scraping.
- Canonical deduplication: A single, verified canonical listing for each real opportunity across global sources.
- Virtualized rendering: UI sustains 60 FPS buttery smoothness even with thousands of active roles.

### STRICT RULE #5: Zero-Boredom Intelligent Presentation & High-Energy Command Deck
- Eliminate monotonous walls of plain text and choice paralysis.
- Data organized into prioritized shelves:
  1. 🚨 *Critical Window (< 72h to close)*
  2. 🏆 *Tier-1 Tech & AI Leaders*
  3. 🎯 *High Fitment Matches (>= 90%)*
- Interactive dual-view: High-Impact Radar Grid + Execution Kanban Pipeline with tactile momentum feedback.

## 📋 CONSOLIDATED FUNCTIONAL REQUIREMENTS (Req 1 – 22)

- **[Req 1: Zero-Lag Opportunity Radar]** Direct tracking of official career ATS endpoints with student eligibility matrix (degree, batch, graduation year) and urgent deadline countdowns.
- **[Req 2: Cryptographic & Official Domain Verification]** DNS & SSL domain lock. Strict quarantine for ghost postings, unauthorized scrapers, or fee-charging scams.
- **[Req 3: Interactive Application Kanban Tracker]** Drag-and-drop lifecycle stages: `Bookmarked` ➔ `Applied` ➔ `Assessment / OA` ➔ `Interview Round` ➔ `Offer / Archived`.
- **[Req 4: Anti-Ban Human-Paced Fast Apply Engine]** Consolidated with Req 17. Multi-field autofill with natural key-stroke pacing to prevent bot-detection/shadowbans. Smart confirmation gate for critical legal questions.
- **[Req 5: Smart Lightweight Digest]** Daily morning/evening compact digest email (< 25 KB) to eliminate student inbox clutter.
- **[Req 6: Secure No-Reply Email Infrastructure]** Dedicated outbound sender identity (`no-reply@carrier-radar.app`) configured with RFC auto-submitted headers to prevent mail loop congestion.
- **[Req 7: Granular Job-Level Alert Suppression]** When a student applies to a job, only that specific job's "Apply Now" reminders are muted. Global career alerts and future openings from that company remain 100% active.
- **[Req 8: Auto-Purging Ephemeral Alerts vs Permanent Applied Dossier]** Inactive/expired unapplied notifications auto-purge. Applied job records and submission receipts are stored permanently.
- **[Req 9: Company Response Inbound Engine]** Autonomous parsing of ATS responses (Greenhouse/Lever) to detect and flag online assessments (OA), interview scheduling, or selection.
- **[Req 10: Multi-Tier Distinct UI/UX Mail Architecture]**
  - *Tier A (Gold/Amber):* New Opportunity Discovery Alert
  - *Tier B (Slate/Navy):* Application Submission & Record Dossier
  - *Tier C (Neon Emerald/Alarm):* Action-Required OA/Interview Link with 3-bullet Action Advisor
  - *Tier D (Royal Purple/Gold):* Selection & Official Offer Milestone with Acceptance Deadlines
- **[Req 11: Composite Priority Ordering Engine]**
  - Default sort: `Closing Soon (< 72h)` ➔ `Fresh Drops (< 48h)` ➔ `Ascending Timeline`.
  - 1-click filters: Urgent First, Fresh Drops, Highest Fitment %, Tier-1 Tech.
- **[Req 12: Multi-Tenant Isolated State]** Zero cross-user data leakage. Clean, isolated student workspace for applications, custom notes, and resumes.
- **[Req 13: Multi-Persona Resume Matcher & ATS Gap Analyzer]** Multiple profile versions (e.g., Full-Stack vs AI/ML) with missing keyword gap detection against job requirements.
- **[Req 14: Compensation & Fair Wage Transparency]** Verified pay ranges, benchmark compensation data, and 1-click filter to block unpaid/exploitative internships.
- **[Req 15: Insider & Referral Outreach Engine]** Identifies alumni and inside engineering presence with 1-click professional cold referral draft templates.
- **[Req 16: Company OA Intelligence & Warm-up Vault]** Company-specific past assessment patterns, frequently tested algorithmic topics, and warm-up practice links.
- **[Req 17: 6 Integrated Operational Modes (Santiago-Inspired & Upgraded)]**
  - 📡 *Live Radar Mode (Scan)*
  - 🧠 *Evaluation Studio (Oferta)*
  - 📄 *Truth-Anchored Resume Studio (PDF)*
  - ⚡ *Execution Pipeline & Kanban (Tracker)*
  - 🚀 *Batch Fast-Apply Engine (Batch)*
  - 📬 *Smart Alert & Notification Center (Pipeline)*
- **[Req 18: Visual Profile Context Engine]** Interactive UI replacing cumbersome manual YAML/Markdown files (`_profile.md` / `portals.yml`).
- **[Req 19: Unified Multi-AI Orchestration Engine]** Seamlessly utilizes specialized intelligence layers (Fast Ingestion, Deep Reasoning, Truth-Anchored CV formatting, Strategy Copilot) under a single zero-setup architecture with optional BYOK (Bring-Your-Own-Key).
- **[Req 20: 100% Autonomous Algorithmic Core]** Core radar, timers, filters, and pipeline operate natively with zero dependency on third-party AI uptime. System never freezes if an AI service is offline.
- **[Req 21: Google AI Studio Integration]** Native, secure server-side Gemini 2.5 integration for lightning-fast, high-capacity reasoning without exposing client keys.
- **[Req 22: In-App Interactive Friendly Guide Copilot]** Always-accessible conversational companion to guide first-time students through every feature in warm, everyday conversational language.
